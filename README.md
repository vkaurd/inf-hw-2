# inf-hw-2
примеры работы
1. Подсчет GC-состава. Что делает: Читает ДНК-последовательности в формате FASTA, считает процентное содержание нуклеотидов G (гуанин) и C (цитозин) и находит строку с самым высоким показателем.
2. Расстояние Хэмминга. Что делает: Посимвольно сравнивает две строки ДНК одинаковой длины и считает количество мутаций (различий между ними).
3. Первый закон Менделя. Что делает: Рассчитывает вероятность того, что у двух случайных организмов из популяции родится потомок с доминантным признаком.
4. Элемент большинства. Что делает: Ищет в массивах число, которое встречается строго чаще, чем в половине случаев (> n/2).
5. Слияние двух отсортированных массивов. Что делает: Объединяет два уже отсортированных списка чисел в один общий упорядоченный массив. 
6. Трансляция РНК в белок. Что делает: Переводит цепочку информационной РНК в аминокислотную последовательность белка по таблице генетического кода до первого стоп-кодона. 
8. Двойная степень вершин графа. Что делает: Для каждой вершины графа находит сумму степеней всех её ближайших соседей.
